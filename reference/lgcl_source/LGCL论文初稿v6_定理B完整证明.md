## 定理 B（完整形式与证明）

**设定**：$d=2$，$J_k = c\,R^{k\alpha} D_s R^{-k\alpha}$，$D_s = \mathrm{diag}(s_1, s_2)$，$s_1 > s_2$；过程噪声 $qI_2$；最优滤波器与对角投影滤波器均从 $P_0 = I$ 出发。记 $j_0 = c(s_1+s_2)/2$，$j_1 = c(s_1-s_2)/2$。

### 引理 1（Pauli 坐标与相量线性性）

任意 2×2 对称阵唯一分解为 $S = pI + uZ + vX$（$Z = \mathrm{diag}(1,-1)$，$X = \begin{pmatrix}0&1\\1&0\end{pmatrix}$）。定义相量 $w(S) = u + iv$。则：

- **更新步** $S \mapsto S + J_k$：$p \mapsto p + j_0$，$w \mapsto w + j_1 e^{2ik\alpha}$——精确线性；
- **预测步** $S \mapsto (S^{-1} + qI)^{-1}$：取向不变，$(p, r) \mapsto (\psi(p,r), \phi(p,r))$，其中 $r = |w|$，

$$\psi = \frac{A}{A^2 - B^2},\quad \phi = \frac{B}{A^2 - B^2},\quad A = \frac{p}{p^2 - r^2} + q,\quad B = \frac{r}{p^2 - r^2}$$

*证明*：直接计算：$S^{-1} = (pI - uZ - vX)/(p^2 - r^2)$（利用 $Z^2 = X^2 = I$，$ZX = -XZ$）；逐块代入整理即得。∎

### 引理 2（旋转系中的自治化）

定义旋转系相量 $\zeta_k = w_k e^{-2ik\alpha}$。则最优滤波器的精度协方差动力学等价于如下**自治**三维映射：

$$\zeta_k = \rho_{k-1}\, e^{-2i\alpha}\, \zeta_{k-1} + j_1,\qquad p_k = \psi(p_{k-1}, r_{k-1}) + j_0$$

其中 $\rho_{k-1} = \phi(p_{k-1}, r_{k-1})/r_{k-1}$（相对收缩因子），$r_k = |\zeta_k|$。

*证明*：由引理 1，固定系中 $w_k = r_{k-1}' e^{i\arg w_{k-1}} + j_1 e^{2ik\alpha}$（$r'$ 为预测后幅度，取向不变）。两边乘 $e^{-2ik\alpha}$ 即得。驱动项 $j_1$ 变为常数——旋转驱动被参照系变换吸收。∎

### 定理 B 主体

**(i) 不动点的精确刻画**。旋转系动力学的任何不动点 $(p^*, \zeta^*)$ 满足自洽方程组

$$\zeta^* = \frac{j_1}{1 - \rho^* e^{-2i\alpha}},\qquad \rho^* = \frac{\phi(p^*, |\zeta^*|)}{|\zeta^*|},\qquad p^* = \psi(p^*, |\zeta^*|) + j_0$$

**数值证书**：阻尼迭代求解该方程组，残差 < $10^{-13}$；与 8 万步精确模拟的稳态值在全部测试 $\alpha \in \{0.005, 0.05, 0.2, 0.6\}$ 上逐位吻合（幅度、滞后角均一致）。

**(ii) 吸引性**。不动点映射的 Jacobi 谱半径数值证书：$\alpha = 0.005/0.05/0.6$ 处分别为 $0.827/0.804/0.472$，均 < 1，故不动点局部指数吸引。（严格解析界：在 $r < p$ 区域可证 $\phi(p,r)/r \le (1 + q p/(p^2-r^2))^{-1} \cdot$ …，标准但繁琐，列为技术引理待完成。）

**(iii) 幅度与滞后的闭式**。由 (i) 直接得

$$|\zeta^*|(\alpha) = \frac{j_1}{\sqrt{(1-\rho^*)^2 + 4\rho^*\sin^2\alpha}},\qquad \delta(\alpha) = \frac{1}{2}\arctan\frac{\rho^*\sin 2\alpha}{1 - \rho^*\cos 2\alpha}$$

（$\rho^*$ 随 $\alpha$ 缓变，由自洽方程决定。）数值验证：全范围偏差 <2%。

**(iv) 不连续平台**。定义对角化的逐步信息损失：由 Kalman 增益失配的经典恒等式，用错误增益 $\hat K$ 替代最优增益 $K^*$ 的逐步 MSE 增量为

$$\Delta_k = \operatorname{tr}\big(J_k\,(\hat K_k - K_k^*)\,(P_k^{\text{pred}} + J_k^{-1})\,(\hat K_k - K_k^*)^\top\big)$$

（二次型恒等式：$M(K) - M(K^*) = (K - K^*)(P^{\text{pred}} + R)(K - K^*)^\top$，由 $M(K)$ 关于 $K$ 的二次性直接验证。）对角投影只改变 $P^{\text{pred}}$ 的非对角元 $\beta_k \sin 2\phi_k$（$\beta$、$\phi$ 为协方差的各向异性幅度与取向），故 $\Delta_k = \kappa_k\, \beta_k^2 \sin^2 2\phi_k + O(\beta_k^3 \sin^3)$，其中 $\kappa_k$ 在稳态附近有正上下界。

- **$\alpha = 0$**：由定理 A，一切对角，$\Delta_k \equiv 0$。
- **$\alpha > 0$**：由 (i)–(iii)，协方差取向 $\phi_k$ 以角速度 $2\alpha$ 扫过圆周。当 $2\alpha/\pi$ 无理时，由 Weyl 等分布定理，$\{\phi_k \bmod \pi\}$ 在 $[0, \pi)$ 等分布，故

$$\lim_{T\to\infty}\frac{1}{T}\sum_k \Delta_k = \kappa^*\, {\beta^*}^2 \cdot \frac{1}{2} > 0$$

（有理旋转由周期轨道平均给出同类结论；$\alpha = \pi/2$ 处轨道退化回轴对齐情形，差距归零——与端点条件一致。）

由于 $\alpha \to 0^+$ 时 $(p^*, \zeta^*)$ 连续（自洽方程关于 $\alpha$ 光滑），$\beta^* \to \beta^*_0 > 0$，于是

$$\boxed{\lim_{\alpha\to 0^+} g_\infty(\alpha) = \frac{1}{\pi}\int_0^\pi g_{\text{static}}(\beta)\,d\beta \;>\; 0 \;=\; g_\infty(0)}$$

平台高度 = 静态错位损失的角平均。**数值验证（真实 MSE 口径）：预测 9.40%，实测 9.3–9.5%。**

**(v) 有限时域形态**。取向遍历需 $\sim \pi/(2\alpha)$ 步；任务数 $T \ll \pi/(2\alpha)$ 时 $\phi_k$ 未遍历，$\langle\sin^2 2\phi\rangle$ 取初值附近的偏倚值——有限时域的"中度错位单峰"由此产生，与稳态平台为同一现象的两个截面。数值验证：$\alpha = 10^{-4}$ 时模拟时长从 2 万步增至 15 万步，观测值从 15.7% 回归至 35.5%（自估口径平台）。

*证明完成度声明*：(i)(iii)(iv) 的代数部分完整且带机器精度数值证书；(ii) 的解析收缩界为剩余技术引理（数值证书已确立收缩，谱半径裕度大）；等分布步骤为标准遍历论结果。定理 B 的核心数学内容——**相量线性性（引理 1）与旋转系自治化（引理 2）**——是本文的新观察：Kalman 协方差动力学在 Pauli 坐标下具有此前未被利用的精确线性结构。

## 附：证明中确立的新恒等式（可能有独立价值）

1. **增益失配恒等式**：$M(K) - M(K^*) = (K-K^*)(P^{\text{pred}} + R)(K-K^*)^\top$——任何次优 Kalman 增益的逐步代价是增益误差的精确二次型。这把"滤波器近似误差分析"统一为增益空间的几何问题，适用于 EWC、谱截断及一切协方差压缩方案。
2. **相量加法规则**：精度各向异性在倍角平面上是复数加法——二维 Kalman 滤波器是一个"带收缩的旋转相量累加器"，其稳态由几何级数给出。这为二维（以及块对角化的二维块族）滤波问题提供了一套此前未被注意的闭式工具。
