# 线性-高斯持续学习（LGCL）：最优滤波及遗忘的精确结构

**论文初稿 v2 · 在《LGCL 技术备忘录》基础上的定理化升级 · 2026-08**

## 摘要（草案）

我们为持续学习提出线性-高斯最小可解模型（LGCL）：潜参数做高斯随机游走，每个任务提供一个以任务协方差为精度的线性测量。该模型中贝叶斯最优持续学习器是卡尔曼滤波器，EWC、SI、回放等方法成为其特定的信息压缩。我们给出对角近似（EWC）次优差距在二维旋转任务族上的**精确解析刻画**（定理 1），发现差距在任务中度错位处达到单峰，且其主导机制是此前未被识别的一项**估计误差与未跟踪漂移的互协方差放大项**。我们进一步给出遗忘的三层精确分解（信息极限 / 记忆结构代价 / 方法近似代价），并在主实验中展示：即使是贝叶斯最优的在线滤波器，也承担着占总遗忘近半的"记忆结构代价"——这是回放类方法优势的理论根源。

## 1. 模型（沿用备忘录 §1，此处仅列记号）

- 状态漂移：$\theta_{k+1} = \theta_k + w_k$，$w_k \sim \mathcal N(0, qI_d)$；
- 任务 $k$ 的测量：$\hat\theta_k = \theta_k + \nu_k$，$\nu_k \sim \mathcal N(0, J_k^{-1})$，$J_k = \frac{n}{\sigma^2}\Sigma_k$；
- 任务 $j$ 的误差度量：$e_j(k) = \mathbb E[(\hat\theta^{(k)}-\theta_j)^\top \Sigma_j (\hat\theta^{(k)}-\theta_j)]$；
- 方法对应：Kalman 滤波 = 最优；EWC = 每步对角投影的 Kalman；回放 = 陈旧度膨胀的测量重放；谱截断 = top-$r$ 特征方向投影 + 弃方向摊平。

## 2. 定理

### 定理 A（对齐情形精确性）

若所有任务的精度矩阵 $J_k$ 在坐标基下同为对角阵，且 $P_0$、$qI$ 对角，则对角投影 Kalman（EWC）与完整 Kalman 逐步相同，次优差距恒为零。

*证明*：归纳。设 $P_{k-1}$ 对角。预测步 $P_{k-1}+qI$ 对角；信息形式更新 $P_k = (P_{\text{pred}}^{-1} + J_k)^{-1}$ 为对角阵之和的逆，仍对角；对角投影为恒等映射。∎

**意义**：EWC 的近似误差完全来自任务精度矩阵的**非对易性**（特征基错位）。这把"何时需要 K-FAC 式的相关结构"转化为一个可计算的几何条件。

### 定理 1（二维旋转任务族的精确差距刻画）

设 $d=2$，$J_k = c\,R^{k}\,\mathrm{diag}(s_1, s_2)\,R^{-k}$（$R$ 为旋转角 $\alpha$，$c = n/\sigma^2$），$\Sigma_k = J_k/c$。定义最优滤波与对角投影滤波的旧任务最终平均误差 $\bar e^*$、$\bar e^{\text{diag}}$。则：

(i)（端点）$\bar e^{\text{diag}} = \bar e^*$ 在 $\alpha = 0$ 与 $\alpha = \pi/2$ 成立。

(ii)（精确计算）对任意 $\alpha$，$\bar e^{\text{diag}}$ 可由如下增广系统精确计算：维护滤波器自估协方差 $P_k$（对角投影版）与增益 $K_k = P_k^{\text{pred}}(P_k^{\text{pred}} + J_k^{-1})^{-1}$，并对增广状态 $X_k = (\theta_k, \hat\theta^{(k)}, \theta_j)^\top$ 的协方差 $C_k$ 做线性递推

$$C_{k} = A_k C_{k-1} A_k^\top + B_k,\quad A_k = \begin{pmatrix} I & 0 \\ K_k & I - K_k \end{pmatrix},\quad B_k = \operatorname{Cov}\begin{pmatrix} w_k \\ K_k(w_k + \nu_k)\end{pmatrix}$$

则 $e_j(T) = \operatorname{tr}\big(\Sigma_j\,[C_T]_{\hat\theta - \theta_j}\big)$，其中 $[C]_{\hat\theta - \theta_j}$ 为相应分块差。

(iii)（放大的机制）令 $D_j = \theta_T - \theta_j$ 为未跟踪漂移尾部，则

$$e_j(T) = \underbrace{\operatorname{tr}(\Sigma_j M_T)}_{\text{滤波MSE}} + \underbrace{(T-j)q\,\operatorname{tr}\Sigma_j}_{\text{漂移滞后}} + \underbrace{2\operatorname{tr}\big(\Sigma_j \operatorname{Cov}(\hat\theta^{(T)} - \theta_T,\ D_j)\big)}_{\text{互协方差项（为负，其模长随增益失配增大）}}$$

其中第三项是次优滤波器差距的**主导放大器**：对角投影使增益失配，估计滞后于随机游走的程度更深，互协方差项的绝对值增大，从而抬高旧任务误差。数值上，该机制将同一滤波 MSE 差距放大约 4 倍（滤波 MSE 口径差距 19.3% → 旧任务口径差距 82.8%，$\alpha=12°$）。

*证明要点*：(i) $\alpha=0$ 即定理 A；$\alpha=\pi/2$ 时 $R^2 = -I$，所有 $J_k$ 仍在坐标基下对角（两轴互换），归入定理 A。(ii) 由模型的线性-高斯性，$(\theta_k, \hat\theta^{(k)})$ 的联合分布为高斯，增广递推为其协方差的精确传播。(iii) 将 $\hat\theta^{(T)} - \theta_j = (\hat\theta^{(T)} - \theta_T) + D_j$ 展开即得；$\hat\theta^{(T)} - \theta_T$ 含有未跟踪的漂移增量（滤波滞后），与 $D_j$ 负相关。∎

**数值验证**（fig7）：精确曲线与蒙特卡洛（400 次/点）在全部 16 个角度上逐点吻合（最大偏差 <2 个百分点，在 MC 误差棒内）。

### 观察 1（稳态不连续性，猜想）

在无限时域稳态下，差距函数 $g(\alpha)$ 在 $\alpha = 0$ 处不连续：$\alpha = 0$ 时 $g=0$（定理 A），但任意 $\alpha > 0$ 时 $g(\alpha) \to g_\infty > 0$（数值上 $g_\infty \approx 35\%$，随 $\alpha$ 缓慢变化并在 $\alpha \to \pi/2$ 处归零）。机制：任意小的持续错位使相关结构在 $O(1/\alpha)$ 步内累积到非对角稳态。**有限时域的"中度错位峰值"与无限时域的"平台"是同一现象的两个截面**。严格证明（稳态 Riccati 不动点关于 $\alpha$ 的分叉分析）留待后续。

### 猜想 1（一般维度）

对一般 $d$ 与任意任务精度族 $\{J_k\}$，对角投影滤波的相对次优差距被任务特征基的错位能量（如 $\sum_k \|J_k - \mathrm{diag}(J_k)\|_F^2 / \|J_k\|_F^2$）的某个单调函数所界定，且在 $q \to \infty$（漂移主导）与 $q \to 0$ 且完全观测时趋于零。数值支持：实验 1（$d=20$ 随机旋转，差距 <1%）与本节二维精确结果一致——**高维随机错位因测度集中而接近对角可解**。

## 3. 遗忘的三层精确分解

对任意方法 $\mathcal A$，旧任务误差可精确分解为

$$\bar e_{\text{old}}(\mathcal A) = \underbrace{\bar e^{\text{smoother}}}_{\text{信息极限}} + \underbrace{\bar e^* - \bar e^{\text{smoother}}}_{\text{记忆结构代价}} + \underbrace{\bar e(\mathcal A) - \bar e^*}_{\text{方法近似代价}}$$

其中 RTS 平滑器给出"全数据 + 完整跨时相关记忆"下的信息极限；Kalman 滤波 = 仅保留当前状态边缘分布的最优器——**它与平滑器的差距不是算法缺陷，而是"只存边缘、不存联合"这一记忆结构的代价**。

**主实验数值**（$d=20, T=10, q=0.05$，200 次平均）：

| 层 | 数值 | 占比解读 |
|---|---|---|
| 信息极限（平滑器） | 0.179 | — |
| + 记忆结构代价（Kalman 滤波） | 1.329 | 最优在线器也须支付，占总遗忘（以 Naive 计）的 **44%** |
| + EWC 近似代价 | 1.343 | 仅 +0.014（高维随机 regime 下对角近似几乎无损，呼应实验 1） |
| Naive 总误差 | 2.796 | 其余 56% 为可避免遗忘 |

**含义**：(1) 回放类方法的优势根源被定位——回放恢复的是部分"跨时联合信息"，即记忆结构代价项，而非改善滤波精度；(2) 任何纯正则化方法（无论多精确）都无法突破滤波器层，**纯正则的可达遗忘下界 = 信息极限 + 记忆结构代价**——这是一个免实验的可证不可能性陈述（在 LGCL 内是定理，在一般情形是可通过 Fisher 信息推广的方向，对应 T2）。

## 4. 升级版图景：方法的空间位置

LGCL 提供了一张"地图"，每个经典方法是一个坐标明确的点：

```
误差
 ↑
 │  Naive ─────────────  零记忆
 │      ╲
 │       ╲   方法近似代价（定理1精确刻画）
 │        ╲
 │  Kalman滤波 ────────  记忆: d² 协方差 (正则化派的上界)
 │      ╲
 │       ╲  记忆结构代价（回放/联合记忆可部分赎回）
 │        ╲
 │  RTS平滑器 ──────────  记忆: 完整跨时联合 (信息极限)
 └──────────────────────────→ 记忆预算
```

率失真语言下（备忘录 §发现 4）：横轴即"码率"，三类方法占据三个码率档位；T2 的目标是画出该平面上的可达区域边界。

## 5. 与备忘录 v1 的差异记录（诚实审计）

- 实验 3 初版（所有任务同基）差距为零 → 修正为逐任务错位后峰值显现；v2 进一步发现**滤波器自估协方差 ≠ 真实 MSE**，须用 Joseph 形式与增广递推——这一修正把理论差距从 3.9% 修正到 82.8% 并锁定互协方差放大机制（定理 1(iii)）。
- 实验 4 初版（完全观测）预算曲线平坦 → 发现可观测性才是记忆约束起作用的条件（保留为发现 4）。
- "小角二次 onset"假设被证伪：稳态下为不连续跳变（观察 1），二次/线性 onset 只是有限时域现象。
