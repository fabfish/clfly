# 线性-高斯持续学习（LGCL）：最优滤波、遗忘的精确结构与记忆的下界

**论文初稿 v3 · 含定理 B（稳态平台）与定理 2（率失真下界）· 2026-08**

> 版本说明：v1 = 备忘录（模型 + 四大实验发现）；v2 = 定理 1（二维精确差距）+ 遗忘三层分解；v3 = 定理 B（稳态平台及其解析预测）+ 定理 2（记忆下界）+ "结构记忆"概念。本文档为自洽的最新版。

## 1. 模型与基本对应（承 v1/v2，简列）

LGCL：$\theta_{k+1} = \theta_k + w_k$，$w_k \sim \mathcal N(0, qI_d)$；任务 $k$ 提供测量 $\hat\theta_k = \theta_k + \nu_k$，$\nu_k \sim \mathcal N(0, J_k^{-1})$，$J_k = \frac{n}{\sigma^2}\Sigma_k$；部分可观测版本取 $J_k = \frac{n}{\sigma^2}U_k U_k^\top$（$U_k$ 为 $d \times o$ 正交列，$o < d$）。贝叶斯最优 = Kalman 滤波；EWC = 对角投影 Kalman；回放 = 存储旧测量重融合；谱截断 = top-$r$ 特征方向投影。

## 2. 定理 A 与定理 1（承 v2，结论不变）

- **定理 A**：任务精度矩阵对易 ⇒ 对角近似精确（EWC 的误差完全来自任务间非对易性）。
- **定理 1**：二维旋转任务族中，对角近似的旧任务误差由增广状态协方差递推精确给出；$g(0)=g(\pi/2)=0$，内部为正、单峰；主导放大机制是**估计误差与未跟踪漂移的互协方差项**（将滤波口径差距放大约 4 倍）。精确理论与蒙特卡洛逐点吻合（fig7）。

## 3. 定理 B：稳态差距的不连续平台

**设定**：定理 1 的旋转族，无限时域稳态。

**定理 B（机制刻画 + 数值验证）**：记 $g_\infty(\alpha)$ 为稳态对角近似差距。则

(i) $g_\infty(0) = 0$（定理 A），但对任意 $\alpha > 0$，$g_\infty(\alpha) > 0$——**$\alpha=0$ 是不连续点**；

(ii) **平台预测**：当 $\alpha \to 0^+$，后验协方差的形状（各向异性）以 $O(1)$ 时间常数平衡，而其取向以 $O(1/\alpha)$ 时间尺度慢漂移、遍历所有角度；因此

$$\lim_{\alpha\to 0^+} g_\infty(\alpha) = \frac{2}{\pi}\int_0^{\pi/2} g_{\text{static}}(\beta)\, d\beta$$

即平台高度 = **静态（不旋转）任务族中固定错位角 $\beta$ 的对角化损失的角平均**。

**数值验证**（fig8）：$s=(1,0.03)$、$q=0.005$、$c=60$ 时，角平均预测 = 33.9%；$\alpha \in [0.001, 0.1]$ rad 的实测稳态差距 = 34.1%–35.1%，吻合。$\alpha = 10^{-4}$ 时 20k 步模拟仅见 15.7%，延长至 15 万步后回到 35.5%——确认了取向遍历时间 $\sim 2\pi/\alpha$ 是收敛到平台的必要条件（这也直接验证了"慢漂移"机制）。

**意义**：这是一个纯正的动力系统结果——持续学习中的近似误差可以**在极限处不连续**：任意缓慢的任务旋转，只要不停，就把对角近似的误差从零推到 O(1) 平台。实践中它警示：任务"几乎不变"的长期部署（慢 concept drift）正是坐标基正则化方法静默失效的场景。

## 4. 定理 2：记忆的率失真下界与"结构记忆"概念

**设定**：部分可观测、无漂移（$q=0$），$\theta \sim \mathcal N(0, P_0)$。

**定理 2（水注法下界）**：设学习者的记忆是关于全部历史数据的任意 $r$ 维线性统计量，任务结构 $\{J_k\}$ 视为已知元数据。则最终平均任务误差满足

$$\bar e_{\text{final}} \;\ge\; \underbrace{\operatorname{tr}(\bar W C)}_{\text{不可约层}} \;+\; \sum_{i > r} \lambda_i\Big(\bar W^{1/2}\,(P_0 - C)\,\bar W^{1/2}\Big),\qquad C = \Big(P_0^{-1} + \textstyle\sum_k J_k\Big)^{-1}$$

其中 $\bar W = \frac{1}{T}\sum_j \Sigma_j$ 为平均任务权重。

*证明要点*：后验均值 $\mu = \mathbb E[\theta \mid \text{data}]$ 是充分统计量，故任意记忆方案等价于压缩 $\mu$；由全方差公式 $\operatorname{Cov}(\mu) = P_0 - C$，问题化为对高斯向量 $\mu$ 在加权 MSE 下的间接率失真——最优为保留白化协方差 $\bar W^{1/2}(P_0-C)\bar W^{1/2}$ 的 top-$r$ 特征方向（Eckart–Young），失真为弃方向特征值之和。∎

**三个直接推论**：

1. **记忆需求的标度**：达到完整记忆性能只需 $r = d$ 个精心选择的数（而非 $O(Td)$）——记忆的临界预算由潜维度决定，与任务数无关。
2. **线性律**：随机观测子空间下，$\lambda_i$ 谱近似平坦 ⇒ 误差随预算近似线性下降（与实验 4v3 的形态一致）。
3. **谱截断的最优性**：在"均值 + 低秩协方差"格式内，保留后验精度的 top-$r$ 方向（即我们的谱截断方案）正是该下界的最优实现——**谱过滤不是启发式，是率失真意义下的最优编码**。

### 4.1 结构性发现：方向信息是隐藏的记忆载体

统一计费实验（fig9，对数轴）暴露了此前文献未明言的事实——**记忆由两种异质资源构成**：

- **数值信息**：基下的坐标值（EWC 的锚点与 Fisher 值；回放的样本内容）；
- **结构信息**：基本身（"哪些方向重要"）。

证据：(a) 谱截断在数值口径下 $r=1$（21 个数）即达 0.088——因为自适应特征基本身是数据依赖的、携带信息的，按含基口径（$d + r(d+1)$ 个数）计费后其"魔法"消失；(b) 回放方案大量隐性使用任务结构元数据（旧测量的精度矩阵参与融合权重）；(c) Naive 在 20 个数预算下误差 4.44，而同预算精灵达 0.042——**预算利用率相差 100 倍**，差距全部来自"存的数是否放在了对的方向上"。

**推论**：持续学习文献中关于"回放 vs 正则"的记忆效率比较，若不明示结构信息的计费口径，结论不可比。建议未来基准报告采用双口径记账。

## 5. 主实验汇总（v1 保留，编号不变）

- **实验 1**（主对比）：高维随机任务下对角近似几乎无损（EWC vs Kalman <1%）；回放的优势 = 额外记忆 + 工作点移动。
- **实验 2**（稳定性-可塑性）：误差随漂移速率单调上升；Naive 仅在极端漂移下逼近最优。
- **实验 3 → 定理 1**：对角近似差距在任务中度错位处单峰（+85%），端点归零。
- **实验 4 → 定理 2**：部分可观测下记忆预算成为硬约束，误差随预算单调下降并饱和；完全观测下预算无关。
- **遗忘三层分解**：信息极限（平滑器 0.179）+ 记忆结构代价（+1.150，占 44%）+ 方法近似代价（EWC 仅 +0.014）。

## 6. 审计记录（本轮修正）

1. 精灵下界 v1 公式漏掉不可约层（$r=d$ 时给出 0 而非完整 Kalman 误差）→ v2 修正为间接率失真形式（r=0 退化为先验误差，r=d 退化为全数据后验误差，两端自洽）。
2. 回放初版实现隐性携带完整协方差记忆（"回放 b=1 打平 Kalman"为假象）→ 修正为纯测量存储 + 逐步重融合，修正后回放按预算单调改善且 $b=T{-}1$ 时回到 Kalman。
3. 定理 B 中超小 $\alpha$ 的"偏离平台"被确认为取向遍历的有限时间效应，延长模拟后回归平台——非但不构成反例，反而独立验证了慢漂移机制。
